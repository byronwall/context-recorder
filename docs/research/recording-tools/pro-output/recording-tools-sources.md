## Conflicts and access limitations

- Screen Studio: newer direct homepage and caption guide supersede older indexed copy about transcription and pricing. Current text-video editing and local/optional-cloud paths are documented. No numeric price is selected from conflicting variants.
- Cap: pricing prose and one comparison cell disagree about unlimited local recording. No numeric cap is invented. The actual license file supersedes blanket MIT marketing; it is a mixed license, with named MIT crate families and AGPLv3 elsewhere. The displayed current download is 0.6.0, not an old issue’s version.
- BrowserStack: Bird Eats Bug is a lineage/alias, not another product. Old help URLs redirected into Testing Toolkit. Current recording and replay FAQs were followed successfully; the old hub is not treated as a complete source for export restrictions.
- Scribe and Guidde: duplicated price-card/table content can conflict; only explicit usable prose gates are adopted, and no uncertain numeric price is quoted. Icon-only feature membership is not reconstructed from lost alignment.
- Tango: `tango.us` redirected to `tango.ai`. Camtasia Snagit is still distinct from Camtasia Editor; a suite bundle does not make each component’s capabilities native in every other component.
- Screenpipe: source-available and local-first do not mean unrestricted open source or exclusively local processing in every mode. Current policy distinguishes optional cloud, sync and connector paths.
- User reports: closed Cap/FluidVoice issues and the older Descript account do not prove present defects. The Screenpipe incident is a failure-class example, not an estimated failure rate. No paid UI or personal-media trial was conducted.
